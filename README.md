Moon Cafe — Python CLI Ordering System

A simple, interactive command-line interface (CLI) cafe menu ordering program written in Python. This application allows users to view menu options, select items, specify quantities, and automatically calculate the total order bill with a clean screen UI.
Features

    Interactive Menu: Displays a structured menu of drinks with real-time pricing.

    Dynamic Bill Calculation: Computes total cost based on selected quantities.

    Cross-Platform Compatibility: Features automatic terminal screen clearing adapted for both Windows (cls) and Linux/macOS (clear).

    Timed UI Transitions: Utilizes slight delays (time.sleep) for smoother screen refreshes.

Tech Stack

    Language: Python 3.x

    Standard Libraries: os, time, platform
